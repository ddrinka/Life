# Agents

The shared conventions come from `.devcontainer/base/agents/AGENTS.md`, which is imported
ahead of this file. `.devcontainer/base` is a clone of
[ddrinka/DevContainer](https://github.com/ddrinka/DevContainer). This file holds only what
is specific to this repository. When a rule belongs to every repository, change it in that
clone and push from there. When a rule belongs only here, change it in this file.

## Project Context

Start at [README.md](README.md). Keep [TODO.md](TODO.md) and
[IMPLEMENTATION.md](IMPLEMENTATION.md) in sync as work proceeds. TODO.md is a
human-readable checklist. IMPLEMENTATION.md holds decisions, code references, and
commands.
